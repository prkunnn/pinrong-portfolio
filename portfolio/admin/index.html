網站內容管理

管理介面使用免費的 Pages CMS。這個頁面不會索取你的 GitHub 密碼。

  1. 先把包含 .pages.yml 的整個網站上傳至自己的 GitHub repository。
  2. 從下方連結登入 Pages CMS，使用 GitHub 帳號授權該 repository。
  3. 點選「九段成長故事・照片」，換圖或修改內容，按儲存後會提交到 GitHub。
  4. GitHub Pages 部署完成後，公開網站會顯示更新。
